# SIDEPOP ☕
### Good Mood. Great Brew.

SIDEPOP is a playful, modern café website concept built to showcase bold visual design, responsive layouts, and interactive web experiences.

## ✨ Features
- Responsive design for mobile and desktop
- Interactive menu category filters
- Playful café-inspired visual identity
- CSS-based illustrations and animations
- Café information and contact call-to-action

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- Vite

## 🚀 Live Demo
https://jovial-narwhal-5a0ddb.netlify.app

## 💻 Run Locally
1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

## 📌 Project Purpose
Created as a portfolio project to practice frontend development, responsive UI design, and interactive website building.
